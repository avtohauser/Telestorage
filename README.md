# Telestorage

Облачное хранилище в виде Telegram Mini App. Файлы хранятся на серверах Telegram (в приватном канале), а на вашем сервере только база с папками, именами и превью.

## Возможности

- Загрузка любых файлов: фото и видео без сжатия, документы, архивы.
- Большие файлы: до 2 ГБ одним сообщением, больше автоматически режется на части (лимит по умолчанию 20 ГБ).
- Загрузка чанками по 8 МБ: если сеть моргнула, загрузка продолжится с того же места, а не с нуля.
- Папки: создание, переименование, перемещение, удаление.
- Вкладка «Медиа»: галерея фото и видео.
- Просмотр фото, стриминг видео с перемоткой (HTTP Range), аудиоплеер.
- Поиск по имени.
- Публичные ссылки, которые открываются в любом браузере без Telegram.
- Можно просто прислать файл боту в чат, и он сохранится в хранилище.
- Доступ только для указанных пользователей (`ALLOWED_USER_IDS`).
- Светлая и тёмная тема подхватываются из Telegram.

## Как это работает

```
Mini App (React)  ──HTTPS──▶  Сервер (Node.js)  ──MTProto (GramJS)──▶  Telegram
  initData в заголовке          SQLite: папки,            приватный канал:
  загрузка чанками по 8 МБ      имена, превью,            1 файл = 1 сообщение
                                id сообщений
```

Бот работает через MTProto, а не через обычный Bot API, поэтому нет лимитов 20/50 МБ и можно скачивать файл с любого места (для перемотки видео).

## Установка

### 1. Бот

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → сохраните **токен**.
2. Mini App отдельно регистрировать не нужно: при запуске сервер сам поставит кнопку меню «Хранилище» с адресом `PUBLIC_URL`.

### 2. API ID и API Hash

1. Зайдите на https://my.telegram.org → **API development tools**.
2. Создайте приложение (название любое) и сохраните **api_id** и **api_hash**.

Они нужны для подключения по MTProto. Бот при этом логинится по токену, а не по вашему аккаунту.

### 3. Канал-хранилище

1. Создайте **приватный** канал (например, «Telestorage»).
2. Добавьте бота в администраторы с правами публиковать и удалять сообщения.
3. ID канала можно узнать после первого запуска: напишите в канале `/id`, бот ответит числом вида `-100…`.

> ⚠️ Не удаляйте канал и не выгоняйте из него бота: файлы живут именно там.

### 4. Сервер

Нужен VPS с Docker и домен, A-запись которого указывает на сервер. Telegram открывает Mini App только по HTTPS, сертификат Caddy получит сам.

```bash
git clone <этот репозиторий> telestorage && cd telestorage
cp .env.example .env
nano .env        # заполните DOMAIN, PUBLIC_URL, BOT_TOKEN, API_ID, API_HASH
docker compose up -d --build
docker compose logs -f app
```

Если `STORAGE_CHANNEL_ID` ещё не известен:

1. Запустите без него.
2. Напишите `/id` в канале.
3. Впишите полученный ID в `.env`.
4. Выполните `docker compose up -d`.

Чтобы закрыть доступ посторонним, укажите свой ID в `ALLOWED_USER_IDS`. Если написать боту, пока вас нет в списке, он покажет ваш ID.

### 5. Готово

Откройте бота → `/start` → «📂 Открыть хранилище» (или кнопка меню слева от поля ввода).

## Переменные окружения

| Переменная | Обязательна | Описание |
|---|---|---|
| `BOT_TOKEN` | да | токен от @BotFather |
| `API_ID`, `API_HASH` | да | с my.telegram.org |
| `PUBLIC_URL` | да | `https://ваш-домен`, адрес Mini App |
| `DOMAIN` | для Caddy | домен без `https://` |
| `STORAGE_CHANNEL_ID` | да* | ID приватного канала (`-100…`) |
| `ALLOWED_USER_IDS` | нет | user ID через запятую; пусто = доступ всем |
| `MAX_FILE_SIZE_MB` | нет | максимальный размер файла, по умолчанию 20480 |
| `PART_SIZE_MB` | нет | размер одной части в Telegram, по умолчанию 1950 (лимит 2000) |
| `UPLOAD_CONCURRENCY` | нет | сколько файлов одновременно отправлять в Telegram |

## Данные и бэкапы

Всё состояние лежит в `./data`:

- `telestorage.db` — база (папки, имена, превью, id сообщений в канале);
- `session.txt` — сессия бота;
- `tmp/` — файлы, которые ещё не отправлены в Telegram.

**Бэкапьте `telestorage.db`**: без неё файлы останутся в канале, но потеряются имена и папки. Хотя у каждого сообщения в канале есть подпись `#u<user> #f<file>` и имя файла, так что восстановить можно.

Место на диске сервера нужно только под временные файлы, пока идёт загрузка. Поэтому свободного места должно быть не меньше, чем самый большой загружаемый файл.

## Разработка

```bash
# бэкенд
cd server && npm i && cp ../.env.example .env && npm run dev   # :8080
# фронтенд
cd web && npm i && npm run dev                                 # :5173, /api проксируется на :8080
```

Вне Telegram запросы не пройдут авторизацию. Для отладки в браузере можно скопировать `initData` из открытого Mini App и положить его в `web/.env.local` как `VITE_DEV_INIT_DATA=...`; он действует 24 часа. Для теста внутри Telegram удобно пробросить локальный сервер через `cloudflared tunnel` или `ngrok` и указать полученный адрес в `PUBLIC_URL`.

## Ограничения

- Mini App не умеет работать в фоне, поэтому автобэкапа галереи телефона нет: загрузка только вручную.
- Пока файл передаётся с телефона на сервер, Mini App нельзя закрывать: если закрыть, файл придётся выбрать заново. Но то, что уже полностью дошло до сервера, отправляется в Telegram в фоне, даже если приложение закрыто.
- Telegram не гарантирует хранение данных для таких сценариев, и за злоупотребления могут ограничить бота. Не храните здесь единственную копию по-настоящему важных файлов.
- Файлы в канале не шифруются, их видят все админы канала.
